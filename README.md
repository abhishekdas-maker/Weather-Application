markdown# Gemini AI App on Cloudflare

A serverless web application powered by [Google AI Studio](https://aistudio.google.com) 

## 🚀 Architecture

* **Frontend / Logic:** Generated via Google AI Studio Build mode.
* **Version Control:** Synced and stored in a GitHub Repository (https://github.com/abhishekdas-maker/Weather-Application/)
* **Hosting & Proxy:** Served via Cloudflare (https://weather-application-2t0.pages.dev/)
